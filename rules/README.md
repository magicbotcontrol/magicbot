# Rules

Este diretório descreve contratos e regras de integração entre o **MagicCopyBot** e sistemas externos (ex.: **ControlCopyIQ**), além de decisões de negócio que impactam banco, UI e automações.

Arquivos:
- `controlcopy-promo-integration.md`: contrato de comunicação de promoções (7/15/30 dias ou nenhuma) para o ControlCopyIQ.
- `copy-campaign-audit-trail.md`: trilha de auditoria (redemptions) e recomendações de observabilidade.
